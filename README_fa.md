## &rlm;Firefox VPN چیست؟

&rlm;**Firefox VPN** یک کلاینت VPN رایگان و متن‌باز است که با استفاده از حساب کاربری فایرفاکس (Firefox Account)، ترافیک اینترنت **تمام برنامه‌های دستگاه** را از طریق زیرساخت **Fastly** و تونل‌های **HTTP/2 و HTTP/3** منتقل می‌کند.

هر حساب فایرفاکس دارای **۵۰ گیگابایت ترافیک رایگان ماهانه** است. این برنامه با پشتیبانی از چندین حساب کاربری، امکان استفاده از مجموع سهمیه‌های آن‌ها را فراهم می‌کند و محدودیت ۵۰ گیگابایت یک حساب را پشت سر می‌گذارد.

&rlm;Firefox VPN برای **اندروید، ویندوز، مک و لینوکس** در دسترس است و کاملاً رایگان، بدون تبلیغات و متن‌باز ارائه می‌شود.

## 💻 نصب و به‌روزرسانی به آخرین نسخه در لینوکس/ مک

> کاربران ویندوز و اندروید به این بخش نیاز ندارند: فایل نصب را از جدول «دانلود مستقیم» بالا بگیرید.

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/armanlife/firefox-vpn-client/main/install.sh | bash
```

<div dir="rtl">

- **مک:** برنامه در Applications نصب می‌شود.
- **لینوکس با محیط گرافیکی (دسکتاپ):** برنامه برای کاربر شما و بدون sudo نصب می‌شود و در منوی برنامه‌ها می‌آید.
- **لینوکس بدون محیط گرافیکی (سرور):** هسته به‌صورت سرویس systemd همراه با پنل تحت وب نصب می‌شود. برای این کار رمز sudo پرسیده می‌شود.
- **اتصال SSH:** چون ممکن است سرور باشد یا کامپیوتر دسکتاپی که از راه دور به آن وصل شده‌اید، اسکریپت می‌پرسد چه چیزی نصب شود.

اگر Firefox VPN از قبل نصب باشد، همین دستور می‌پرسد که به‌روزرسانی شود (پیش‌فرض، با زدن Enter) یا حذف، و موقع حذف می‌پرسد که حساب‌ها و تنظیمات هم پاک شوند یا بمانند.

### 🌐 پنل تحت وب

پنل تحت وب برای **سرورهای لینوکس بدون محیط گرافیکی (CLI)** است، جایی که برنامه اجرا نمی‌شود. در ویندوز، مک، اندروید و لینوکس دسکتاپ از خود برنامه استفاده کنید.

این پنل داخل هسته است، با هر مرورگری باز می‌شود و همهٔ کارهای برنامه را انجام می‌دهد: افزودن و مدیریت حساب‌ها و حجم باقی‌ماندهٔ هر کدام، انتخاب سرور و تست تأخیر واقعی، تست اتصال و IP عمومی، لاگ زنده، و همهٔ تنظیمات.

- **آدرس:** http://127.0.0.1:10820
- **پروکسی:** SOCKS5 و HTTP روی `127.0.0.1:10810`؛ برنامه‌ها یا دستگاه‌های دیگر را به این آدرس وصل کنید.
- **دسترسی از کامپیوتر خودتان به پنل سرور:** پنل به‌طور پیش‌فرض فقط روی خود سرور باز است، که امن‌ترین حالت است. با یک تونل SSH بازش کنید و بعد در مرورگر خودتان http://127.0.0.1:10820 را باز کنید:

</div>

```bash
ssh -L 10820:127.0.0.1:10820 user@your-server
```

<div dir="rtl">

دستورهای سرویس روی سرور:

</div>

```bash
sudo firefox-vpn add-account           # sign in to a Firefox Account (also possible in the web panel)
sudo firefox-vpn status                # the service and its state
sudo firefox-vpn logs                  # follow the service's log
sudo firefox-vpn restart               # restart the service
sudo firefox-vpn set-dashboard-login   # set the web panel's username and password
```
